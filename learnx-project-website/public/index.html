Literature survey

Research foundations across four learning experiences.

LearnX draws on image generation, retrieval, speech and handwriting research to investigate how specialized AI pipelines can support biology learning.

Controllable visual generation

Diffusion models generate images from text; ControlNet adds spatial guidance from sketches. Segmentation and vision-language reasoning support exploration after generation.

SDXL · Xinsir Scribble ControlNet · SAM 2

Grounded assessment and retrieval

Retrieval-augmented generation conditions language-model outputs on retrieved passages. LearnX uses this approach for document-grounded questions, revision notes and spoken answers.

Lewis et al. · RAG (2020)

Efficient model adaptation

LoRA adapts pretrained models by learning a small set of additional weights. It provides a basis for domain-specific prompt generation and assessment models.

Hu et al. · LoRA (2021)

Multilingual spoken revision

Whisper studies speech recognition across languages. Language-specific recognition and speech synthesis models extend the audio component’s English, Sinhala and Tamil revision workflows.

Radford et al. · Whisper (2022)

Handwritten note recovery

TrOCR uses an encoder–decoder Transformer for text recognition. Sinhala handwriting adaptation and image enhancement address the project’s note-recovery task.

Li et al. · TrOCR (2021)

Feedback and iterative refinement

Reflexion and Self-Refine study feedback-driven retries. LearnX investigates critique and regeneration in its visual pipeline, with reviewed memory and validation before durable updates.

Reflexion (2023) · Self-Refine (2023)

Research gap

From isolated AI capabilities to useful learning workflows.

The research reviewed above establishes strong methods for individual tasks. LearnX investigates the following needs when applying them to biology study.

  • Visual control and explanation: a generated image also needs checks for requested structures, editable labels and meaningful region exploration.
  • Assessment-to-revision continuity: quiz scores should guide difficulty, identify weak concepts and connect learners to relevant notes and learning resources.
  • Multilingual access to study material: spoken questions and answers need document grounding and language-appropriate recognition and synthesis.
  • Sinhala handwriting recovery: unclear handwritten notes require recognition and translation evaluated on the target writing and subject domain.
  • Evidence for improvement: generated outputs and feedback-driven updates require component-specific evaluation before claims of learning benefit can be established.

Research problem

How can AI support biology learners through explorable visuals, adaptive assessment and resources, multilingual revision, and recovered handwritten notes?

LearnX investigates how each workflow can preserve relevant learning context, check generated content and respond to learner needs. The four subsystems are developed and evaluated independently; a unified learner profile is a future research direction.

Research objectives

One research aim, four component objectives.

Develop and evaluate specialized AI workflows that make biology study more interactive, responsive and accessible.

  1. Interactive visualizations: generate educational images from text or sketches, support anatomy-focused validation, and enable editable labels, region explanations and optional 3D exploration.
  2. Multilingual audio review: support spoken or typed questions about study documents and return grounded revision answers with language-specific speech in English, Sinhala and Tamil.
  3. Adaptive assessment and resource recommendation: generate document-grounded questions, evaluate answers, adapt difficulty and recommend concept notes and resources for weak topics.
  4. Intelligent note generation: enhance handwritten Sinhala note images, recover their text and provide Tamil and English translations.
  5. Evaluation: assess output quality and reliability using suitable component metrics, and validate reviewed visualization memory or skill updates before activation.

Methodology

Inputs, specialized processing, validation and revision.

Four independently deployable subsystems apply task-specific models and checks. LangGraph orchestrates the visual, audio and assessment workflows; the notes API coordinates enhancement, OCR and translation services.

  1. 01Collect learning inputs

    Text prompts and sketches, study documents, recorded questions and handwritten Sinhala images.

  2. 02Process by component

    Generate and inspect visuals; retrieve evidence and build assessments; transcribe and answer questions; recognize and translate handwriting.

  3. 03Validate outputs

    Use visual critics and anatomy checks, question and answer validation, source-grounded retrieval, and OCR error measurement.

  4. 04Support further study

    Return interactive visuals, adaptive practice and resources, spoken revision, or recovered notes with translations.

Visualizations

Image–text alignment, visual and pedagogical scores, anatomy structure and relation checks, label quality and latency.

Audio review

Speech recognition error, retrieval relevance, answer grounding and language-specific speech quality.

Assessment and resources

Question validity, Bloom’s-level alignment, difficulty adaptation, weak-topic analysis and resource relevance.

Note recovery

Character error rate, word error rate, exact-match accuracy and inference latency against a baseline.

Component quality and learner outcomes are separate evaluation questions. A unified application, shared learner profile and cross-component learning-outcome study remain future work.

01

Kojithan P. Y · IT22264220

Interactive visualizations

Turn a learning prompt or learner-drawn sketch into an image that can be labeled, explored and optionally converted into a 3D asset.

  1. Text and anatomy generation

    Qwen2.5-3B-Instruct enhances the request or extracts a structured anatomy specification. Validated prompts guide FLUX.1-dev image generation.

  2. Sketch-to-image: two cooperating models

    SDXL Base 1.0 generates the image. A separately loaded Xinsir Scribble ControlNet conditions SDXL on the drawing’s strokes. Together they form the sketch-to-image pipeline; learners can adjust sketch adherence and edit saved strokes.

  3. Evaluation and reflection

    Qwen2.5-VL and CLIP support image evaluation. Anatomy checks assess the requested structures and view; the text-generation workflow supports up to two quality retries.

  4. Interactive exploration

    SAM 2.1 and Qwen2.5-VL support selected-region analysis. Learners can edit labels and arrows, export labeled SVGs and request optional Hunyuan3D-2 conversion.

Learning output
Generated 2D visuals, editable annotations, region explanations and optional textured 3D assets.
Evaluation focus
Visual alignment, pedagogical clarity, anatomy checks, annotation quality and response time.

02

Baskaran V · IT22172600

Multilingual audio review

Ask questions about uploaded lecture material by voice or text, then revise through grounded answers and language-specific audio.

  1. Speech and transcript processing

    Whisper large-v3 and Sinhala- and Tamil-specific recognition services transcribe questions. Gemma-based transcript correction preserves the learner’s intended question.

  2. Document-grounded answers

    BGE-M3 embeddings, BM25, Reciprocal Rank Fusion and reranking retrieve supporting passages. Gemma 4 12B IT with component adapters generates answers; a Qwen localization service supports the alternate localization path.

  3. Listen and revise

    Kokoro, Indic Parler-TTS and SinhalaVITS provide language-specific synthesis when enabled. Document-to-audio revision supports transcripts, WAV download and playback-speed control.

Learning output
Source-grounded answers and English, Sinhala or Tamil audio revision, depending on the configured speech services.
Evaluation focus
Recognition accuracy, retrieval relevance, answer grounding and speech quality.
Explore component source
03

Nishara T · IT22223876

Adaptive assessment & resource recommendation

Connect assessment performance to the next study action through personalized questions, progressive feedback, concept notes and learning resources.

  1. Build grounded practice

    Ingestion and knowledge agents parse uploaded PDF, DOCX, PPTX or TXT material and retrieve relevant passages. A fine-tuned Qwen2.5-7B model generates multiple-choice, structured and essay-style questions with Bloom’s-level guidance.

  2. Evaluate and adapt

    Evaluation and adaptive agents score responses, provide progressive hints and adjust subsequent question difficulty from session performance.

  3. Recommend resources

    The recommendation agent identifies weak topics, builds source-grounded concept notes and discovers or selects relevant learning-resource links. Analytics summarize scores, strong and weak topics, and difficulty progression.

Learning output
Adaptive quizzes, answer feedback, performance analytics, weak-topic revision notes and recommended learning resources.
Evaluation focus
Question validity, grounding, Bloom’s-level alignment, difficulty progression and recommendation relevance.
Explore component source
04

Sarmitha S · IT22637482

Intelligent note generation

Recover readable study content from handwritten Sinhala note images and make it available in Sinhala, Tamil and English.

  1. Enhance the note image

    A fine-tuned Swin2SR service produces an enhanced image for comparison and download.

  2. Recognize Sinhala handwriting

    The OCR service deskews the original image, detects lines and compares primary and secondary TrOCR transcriptions. Recognition uses original pixels to preserve the handwriting characteristics expected by the model.

  3. Translate recovered text

    NLLB-200 generates Tamil and English versions alongside the Sinhala transcription. Qwen-based validation and SinhaLM correction are experimental extensions to this core workflow.

Learning output
Original and enhanced images, extracted Sinhala text and Tamil/English translations.
Evaluation focus
Character error rate, word error rate, exact-match accuracy and latency on handwritten-note examples.

Technologies used

The research technology stack.

Interfaces, services and model checkpoints supporting the four research workflows.

Frontend & interaction

React · TypeScript · Expo / React Native / React Native Web for the visual and notes interfaces. Next.js and Tailwind CSS for the audio and assessment web interfaces.

React Three Fiber · Three.js · React Native SVG for interactive visuals and 3D exploration.

Backend & AI orchestration

Python · FastAPI · Uvicorn · Pydantic. LangGraph coordinates visual, audio and assessment workflows.

PyTorch · Hugging Face Transformers / Diffusers · PEFT with LoRA / QLoRA · vLLM for selected inference services.

Database, retrieval & storage

Visual: Supabase PostgreSQL, pgvector, Auth and Storage; IndexedDB for local browser persistence.

Audio: Supabase and ChromaDB.
Assessment: SQLite and ChromaDB, including SQLite workflow checkpoints.

Serving & deployment

Modal for GPU model inference. GitHub and GitHub Actions support source control and component CI/CD.

The visualization API and worker use AWS EC2; Vercel serves the research website and visualization web client.

Models by research component

M = million parameters; B = billion parameters; ≈ indicates a rounded model size. Base-model sizes exclude separately trained LoRA adapters. Vision-language totals include the vision encoder. Each checkpoint links to its model card or source.
