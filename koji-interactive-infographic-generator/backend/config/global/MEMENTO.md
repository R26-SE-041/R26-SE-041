# Global memento

Only multi-agent, human-reviewed lessons belong here. Raw conversations, outputs, personal data, and one-off preferences must remain in structured storage.

## Proven lessons

- Preserve the original learning objective across targeted regeneration.
- Regenerating an upstream artifact invalidates dependent downstream artifacts.
- User feedback is evidence, not an instruction that can override safety or factual accuracy.
- Role separation improves auditability: generators produce, grounding components localize, and independent evaluators verify.
- A component that cannot consume language instructions must be controlled with validated inputs, thresholds, and output checks rather than a prompt persona.
