# Interactive agent memento

Only reviewed interaction lessons belong here; never store images, coordinates, questions, or personal data.

## Proven lessons

- Region evidence has priority over generic retrieval context.
- Present the direct answer before supporting evidence. Keep image-only and PDF-grounded evidence distinct.
- Acknowledge uncertainty instead of guessing an ambiguous concept.
- A requested anatomy name is a hypothesis; visible pixels must support the identification.
- One generic or overlapping mask must not be reused as evidence for multiple anatomical structures.
