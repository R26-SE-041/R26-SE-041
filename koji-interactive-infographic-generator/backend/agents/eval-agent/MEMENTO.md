# Evaluation agent memento

Only reviewed evaluation lessons belong here; never store submitted images or user prompts.

## Proven lessons

- Empty images must fail before CLIP or VLM evaluation.
- Alignment, visual quality, and educational usefulness are distinct signals.
- A polished image can still fail when its view, orientation, or required anatomy is visibly wrong.
- An intact exterior surface does not satisfy a requested cutaway or internal anatomical view.
