EduVision: A Self-Improving Multi-Agent System

Slide 1 / 5

Curriculum-Grounded Multi-Modal Infographics & 3D Model Generation

Transforming ambiguous educational topics into anatomically accurate, interactive SVG diagrams with explorable 3D geometry and self-improving memory.

❌ The Research Problem
  • • Visual & Factual Hallucinations: Standard generative models (FLUX/Midjourney) generate artistic images with garbled text labels and anatomical errors.
  • • Static & Flat Output: Traditional outputs are static bitmaps with 0% student interactivity (cannot click parts or inspect in 3D).
  • • Zero Memory Retention: Baseline pipelines repeat the same errors across sessions without persistent learning.
✅ Our Proposed Multi-Agent Innovation
  • • Multi-Agent Pipeline: Specialized Prompt, Image (FLUX.1-dev), SAM-2 Segmentation, and 3D Mesh (Hunyuan3D) agents.
  • • Dual-Critic Reflexion: Multi-layer image & pedagogical critic with automated targeted retry loops.
  • • Continuous Feedback Memory: Supabase pgvector embedding memory (memento.md) that evolves over time.

1️⃣ Decoupled Micro-Agent Design (Modal Cloud)

Prompt, Image, Segmentation, 3D, and Evaluation agents run as isolated serverless GPU containers with typed contracts.

2️⃣ Synchronization Guarantee

The 3D Agent and SAM-2 segmenter only execute on the Dual-Critic approved 2D diagram, ensuring zero mismatch between 2D labels and 3D geometry.

3️⃣ Tiered Memory System

Separates fixed procedural rules (SKILL.md) from user feedback-evolved durable memory (memento.md via Supabase).

🔬 Quality Assurance & Scientific Validation

Multi-Tiered Image Validation Pipeline

Slide 4 / 5
1️⃣ Quantitative Alignment
CLIPScore Engine
  • • Model: openai/clip-vit-base-patch16 via torchmetrics.
  • • Measurement: Computes sub-second cosine semantic similarity between generation prompt and image tensor.
  • • Role: Rapid quantitative sanity filter before expensive VLM analysis.
2️⃣ Pedagogical & Visual VLM
Qwen2.5-VL-7B-Instruct
  • • Visual Alignment (0-10): Verifies image details match user prompt intent.
  • • Pedagogical Clarity (0-10): Assesses visual hierarchy and readability.
  • • Actionable Feedback: Returns structured guidance for Reflexion retries.
3️⃣ Domain Anatomy Critic
Spec-Based Verification
  • • Structure Recall: Checks mandatory anatomical organs / chambers.
  • • Orientation & Laterality: Inversion & connection validation.
  • • Clean Compliance: Rejects embedded burned-in text (embedded_text_present == False).
Automated Approval Gate: Output passes only when Visual ≥ 7.0, Pedagogical ≥ 7.0, and Anatomy Hard Failures == 0.
